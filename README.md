MyPatientHUB 🏥

A healthcare web application designed to help users access healthcare services in one place.

📌 About the Project

MyPatientHUB is a healthcare platform that provides a simple and user-friendly interface for exploring healthcare services. Users can navigate between different pages to find doctors, clinics, pharmacies, and other useful features.

✨ Features

- Dashboard — View the main dashboard.
- Find Doctor — Explore the doctor section.
- Find Clinic — Access clinic information.
- Appointments — Navigate to appointment services.
- Marketplace — Explore available products and services.
- Find Pharmacy — Browse pharmacy products.
- My Dependents — Manage dependent information.
- My Account — Access account-related features.
- Settings — View application settings.
- Login Page — Access the login interface.

🛠️ Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- React Router
- Font Awesome

💻 Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/samjan55/MyPatientHUB.git

2. Open the project folder:
   
   cd MyPatientHUB

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.

📱 Responsive Design

The interface is designed to support desktop, tablet, and mobile screen sizes.

🎯 Project Goal

The goal of MyPatientHUB is to create an accessible and user-friendly healthcare platform that brings different healthcare services together in one place.
